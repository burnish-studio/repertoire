# Perspective Convention

Any document that uses first or second person pronouns must declare its perspective
by referencing this standard immediately below the h1.

| Pronoun    | Refers to |
| ---------- | --------- |
| I / me     | The user  |
| You / your | The agent |

Without a declared convention, pronouns in written documents are ambiguous — "you"
could mean the reader, the agent, or the user depending on assumed context. This
standard fixes the meaning so any reader, human or agent, knows immediately who is
being addressed.
