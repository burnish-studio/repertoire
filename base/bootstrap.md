# Repertoire

This project carries repertoire — standards that govern how work is done here, skills
ready for use, and templates showing correct form. They live in `.agents/`. The
operative norms of every standard present follow this preamble; they are binding. Read
a standard's full text in `.agents/standards/` when you need its rationale or its edge
cases.

Before responding to any task, check whether a relevant skill applies. If one does,
read its `SKILL.md` and follow it directly — announce which skill you are using. Do
not work from memory of a skill; do not summarise or paraphrase its instructions.

When you create anything meant for agent consumption — a skill, a standard, a
template, an instruction file — create it through the authoring skills
(`write-a-skill`, `write-a-standard`, `codify`) and check it with `audit`. What you
create is governed by the same norms as everything else here.
