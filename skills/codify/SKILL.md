# Codify

_Perspective: [standards/perspective/STANDARD.md](../../standards/perspective/STANDARD.md)_

Take something understood from discussion and place it correctly into the repertoire
as the right artifact type, in the right form, conforming to all applicable standards.

---

## What done looks like

A file that could have been written with full prior knowledge of the repertoire — not
a transcript of the session, not a summary of what was discussed, but a clean artifact
that reads as though it was always there. It conforms to every applicable standard and
passes the self-consistency check.

---

## How to approach it

First, determine the right artifact type. The test:

- Does this govern how things should be done generally? → standard
- Does this describe a repeatable action with an output/result in mind? → skill
- Does this show correct form for something? → template

If the answer is not immediately clear, the concept may not be sufficiently resolved
yet. You should clarify before writing — a poorly placed artifact is harder to fix than a delayed
one. Also consider if the concept is actually a combination of multiple artifacts. If so,
you must write each artifact separately and ensure they reference each other correctly.

Once the type is determined, write the artifact per its governing standards. For a
skill, apply `skills/write-a-skill/SKILL.md`. For all artifacts, apply
`templates/frontmatter/TEMPLATE.md` and all standards in `standards/`. You must write at the level of the artifact type, not at the level of the conversation that produced it.

You must check the result against `standards/self-consistency/STANDARD.md` before considering it done.

---

## What not to do

- You must not write a transcript or summary of the discussion. Write the artifact the discussion resolved into.
- You must not place something in the wrong type because it is close enough. The taxonomy is precise — use the test.
- You must not carry session language, caveats, or construction notes into the artifact. It must read cold.
- You must not consider it done if it would require context from this session to be fully understood.
